# Урилга

Энэ репозиторийг GitHub Pages ашиглан онлайнаар нийтлэх заавар:

1. Энэ файлуудыг GitHub дээрх шинэ repository-д оруулна (upload хийнэ).
2. Repository-н **Settings → Pages** руу ороод, **Source**-г `main` branch, `/ (root)` folder гэж сонгоод **Save** дарна.
3. Хэдэн минутын дараа `https://<таны-username>.github.io/<repo-нэр>/` хаягаар урилга нээгдэнэ.

`index.html` файл нь урилгын бүх агуулгыг (лого, мэндчилгээ, хаяг, countdown timer) агуулсан бие даасан нэг файл тул нэмэлт тохиргоо шаардлагагүй.
